# 島旅フェリー予約 — 伊平屋・伊是名共通予約プロトタイプ

GitHub Pagesで公開する、スマートフォン最優先の操作可能プロトタイプです。実際の予約・決済・個人情報送信・メール送信は行いません。伊是名の画面は現行サービスを示すものではなく、「共通予約システム構想」のデモです。

## 現在確認できる運航・予約制度

### 伊平屋

- 航路：運天港 ⇄ 前泊港、所要時間 約80分
- 通常ダイヤ例：運天発 11:00／15:00、前泊発 09:00／13:00
- 料金：大人 片道2,480円・往復4,720円、小人 片道1,240円・往復2,360円
- 環境協力税：100円。正確な免除条件は要確認
- 現在の予約方法：旅客オンライン予約購入あり
- 車両予約：窓口対応

### 伊是名

- 航路：運天港 ⇄ 仲田港、所要時間 約55分
- 通常ダイヤ例：運天発 10:30／15:30、仲田発 09:00／13:30
- 料金：大人 片道1,840円・往復3,500円、小人 片道920円・往復1,750円
- 環境協力税：18歳以上100円。正確な免除条件は要確認
- 本プロトタイプ上のオンライン予約：正式な現行サービスではなく提案機能
- 現在の予約方法・車両予約方法の詳細は運航事業者への確認が必要

通常ダイヤ `scheduledTimetable` と本日の運航情報 `demoOperationStatus` は別データです。`officialUpdatedAt` と `fetchedAt` も分離し、デモモードでは公式更新時刻に見える表示を行いません。

## 今回実装する共通予約システム案

- 1画面1質問：島 → 出発方向 → 片道／往復 → 日付 → 便 → 人数 → 乗船者 → 確認 → 決済 → QR乗船券
- 伊平屋は `onlineBookingStatus: current`、伊是名は `onlineBookingStatus: proposed`
- 運航状態（通常・時刻変更・欠航・運航未定・臨時便）と予約受付状態（予約可能・残りわずか・満席・受付終了・予約対象外）を分離
- Asia/Tokyoの現在時刻と本日の運航情報から次便を計算
- 便ごとの定員・予約人数・残席・予約枠管理。満席・欠航・受付終了便は選択不可
- 往路・復路両方の残席と選択人数を照合
- 代表者 `bookingContact` と乗船者 `passengers[]` を分離。氏名・電話・メール形式を画面内で検証
- 決済中の「予約枠の仮確保」と、失敗・時間切れ時の開放を表示
- 料金マスタで片道・往復を別管理し、乗船運賃・環境協力税・合計を分離表示
- 予約番号による予約確認、QR状態、便変更、キャンセル、返金状況
- 欠航予約では欠航案内・返金状況・他便変更・公式運航情報を優先表示
- 管理画面：今日確認すること、便ごとの定員・残席・予約枠、運航状態の手動変更設計、操作履歴、乗船者一覧
- 予約途中の非個人情報を `sessionStorage` に一時保存し、ブラウザ履歴と予約ステップを連動

配信データは `dist/data/config.js` に分離しています。個人情報のブラウザ保存可否・保存期間・暗号化・アクセス権限は本番設計時に要確認です。生年月日・住所を必須にするか、正式な割引・税免除・変更・取消・返金条件、公式運航情報の取得方法も要確認です。

## 将来的に検討するもの

- 車両オンライン予約：車両種別、ナンバープレート、車両長、往路／復路、車両予約枠

本システムはフェリーの予約・運航情報・乗船券・予約確認・管理業務に集中します。
